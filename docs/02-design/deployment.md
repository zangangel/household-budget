# Apps Script 배포 계획

## 1. 프로젝트 생성

GitHub 저장소의 Apps Script 소스 파일을 Google Apps Script 프로젝트에 업로드한다. `gws script projects create`로 독립형 프로젝트를 만들고, `gws script +push --script SCRIPT_ID --dir apps-script`로 파일을 동기화한다. `+push`와 `updateContent`는 프로젝트의 기존 파일을 모두 교체하므로 업로드 전 파일 목록을 확인한다.

## 2. 초기화

1. `setupWorkbook()`을 수동 실행한다.
2. 권한 요청에서 Google Sheets 접근을 승인한다.
3. 생성된 스프레드시트의 헤더와 기본 카테고리를 확인한다.
4. `getAppConfig()`와 거래 등록을 테스트한다.

## 3. 버전 및 웹앱 배포

소스를 업로드한 뒤 Apps Script 버전을 만들고, 해당 버전 번호를 지정해 배포한다. 배포는 현재 HEAD 파일 자체가 아니라 명시한 버전에 고정한다.

- 실행 사용자: 나
- 접근 사용자: 나만
- 배포 URL: `/exec`
- 개발 중에는 `/dev` 테스트 URL을 사용

## 4. 검증 체크리스트

- 빈 입력, 음수 금액, 잘못된 날짜가 차단되는가
- 수입·지출 요약이 시트 값과 일치하는가
- 삭제 후 원본 행은 보존되고 화면에서는 숨겨지는가
- 동시에 두 번 저장해도 중복/행 충돌이 없는가
- 다른 Google 계정으로 접근할 수 없는가
- 스프레드시트 직접 편집 후에도 화면이 안전하게 동작하는가

## 5. 운영 원칙

- 저장소는 비공개 유지
- Apps Script 배포 권한은 최소 권한으로 유지
- 시트 버전 기록과 정기 다운로드를 백업 수단으로 사용
- 공유 기능을 추가하기 전 사용자별 데이터 격리부터 재설계
