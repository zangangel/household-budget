# Apps Script 웹앱 화면 설계

## 화면 목록

- 대시보드: 월별 요약, 내역 입력, 최근 내역
- 설정/도구: 시트 열기, 데이터 새로고침, 향후 CSV 내보내기

## MVP 와이어프레임

```text
+--------------------------------------------------+
| 오늘의 가계부                    [Google 계정]     |
+--------------------------------------------------+
| 이번 달의 흐름                    [조회 월]       |
| 돈의 흐름을 한눈에 정리해요.                     |
+--------------------------------------------------+
| [수입]             [지출]             [잔액]       |
+--------------------------------------------------+
| 내역 추가                    | 선택 월 내역       |
| [지출 | 수입]                | 날짜  카테고리     |
| 금액                         | 금액         삭제  |
| 날짜 / 카테고리              |                  |
| 메모                         |                  |
| [내역 저장하기]              |                  |
+--------------------------------------------------+
| [새로고침]                         [시트 열기]     |
+--------------------------------------------------+
```

## 상태별 화면

- 로딩: 요약 카드와 목록에 로딩 표시
- 빈 상태: “선택한 월의 내역이 없습니다” 표시
- 성공: 저장 후 요약과 목록을 함께 갱신
- 오류: 권한 만료, 네트워크 오류, 입력 검증 오류를 사용자 언어로 표시

## 주요 흐름

```text
웹앱 열기
  -> Google 권한 확인
  -> 월 선택
  -> google.script.run.getSummary / listTransactions
  -> 내역 입력
  -> google.script.run.createTransaction
  -> 요약/목록 갱신
```
