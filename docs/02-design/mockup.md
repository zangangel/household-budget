# 초기 화면 설계

## 화면 목록

- 대시보드: 월별 요약과 내역 입력·목록을 한 화면에 제공
- 향후 내역 분석: 카테고리별 지출과 월간 추이를 제공
- 향후 설정: 데이터 내보내기, 가져오기, 저장소 초기화

## MVP 와이어프레임

```text
+--------------------------------------------------+
| 오늘의 가계부                    [내 기기에만 저장] |
+--------------------------------------------------+
| 이번 달의 흐름                    [조회 월]       |
| 돈의 흐름을 한눈에 정리해요.                     |
+--------------------------------------------------+
| [수입]             [지출]             [잔액]       |
+--------------------------------------------------+
| 내역 추가                    | 최근 내역          |
| [지출 | 수입]                | 날짜  카테고리     |
| 금액                         | 금액         삭제  |
| 날짜 / 카테고리              |                  |
| 메모                         |                  |
| [내역 저장하기]              |                  |
+--------------------------------------------------+
```

## 반응형 규칙

- 모바일: 입력 패널 아래에 내역 목록을 배치한다.
- 태블릿 이상: 입력과 목록을 2열로 배치한다.
- 500px 이하: 날짜와 카테고리 필드를 세로로 쌓는다.

## 주요 흐름

```text
앱 열기 -> 조회 월 확인 -> 내역 입력 -> 저장 -> 요약/목록 갱신
                                  └-> 삭제 -> 요약/목록 갱신
```
